種別バッジ

三つの種別が同じ一覧に混在する。 どれが何なのかを、色に頼らず見分けられる必要がある。

色と形の二重符号

三つの種別ThreadTypeBadge
課題朱 #c8402c / 四角
議論藍 #2c4a75 / 丸
質問緑 #3f6b52 / 菱形

バッジの左にある印は種別ごとに形が違う。 朱と緑の判別がつかない場合でも、四角と菱形で見分けられる。 文字も併記しているので、印が見えなくても読める。

三重に符号化しているのは冗長に見えるが、 一覧の行は密度が高く、文字が小さい。 形の違いは、文字を読む前に視野の端で処理できる。

形の割り当て

種別形理由
課題四角輪郭が閉じている。終わりの形が決まっているものを表す
議論丸方向を持たない。どこへ向かうか決まっていないものを表す
質問菱形四角を傾けた形。判断の分岐を表す図法から借りた

使う場所と大きさ

大きさは一種類しか作らない。 一覧の行、詳細画面の見出し、ガントの行名。 どこでも同じ大きさで出す。

並べたとき一覧の行での見え方
議論検索の要件をどうするかオープン佐WEB-3
課題検索APIの実装40%田WEB-7
質問全角の正規化はどこでやっている？クローズ鈴WEB-9

種別は変わらない

スレッドの種別は作成後に変更できない。 そのためこのバッジは編集の入口にならず、常に表示専用である。 押せそうな見た目にしない。
