進捗を色の変化ではなく、バーの内側の塗り分けで表している。 色を変えると「進捗率が高い＝良い」という価値判断が乗る。 塗り分けなら、どこまで進んだかという事実だけを示せる。

はみ出し警告

子の期間が親の期間の外に出ているとき、子のバーを黄色にし、親の行に印を出す。

はみ出しの例親と子の関係
課題検索機能の刷新⚠
課題検索APIの実装
課題検索UIの実装

システムは日付を書き換えない。 親の締切を延ばすのか、子を前倒しするのかは人が決める。

掴めない見た目にする

バーはドラッグできない。 そのため、掴めそうな見た目にしない。 端に取っ手を付けず、カーソルも変えない。 ホバーで浮き上がらせることもしない。

期間の変更はスレッドの詳細画面から行う。 バーをクリックすると詳細へ移動する。
