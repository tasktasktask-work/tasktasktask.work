この画面を開く人は、まだこのシステムの中に何も持っていない。 アカウントも、組織も、招待もない。 だから最初に訊けるのは、メールアドレスひとつだけである。

確認が先、組織が後

アドレスを確認してからでないと、組織は作れない。 organizations の行は、 メールのリンクを踏んだ先の画面で初めて生まれる。

先に組織を作って後から確認する形にすると、 「まだ確認されていない組織」を誰がいつ掃除するのかが、新しい問いとして残る。

送信は同じアドレスにつき3分に一度まで。 間隔の中で押されたときも、この画面が出る。

作った人が、その組織の組織管理者になります。

slug の欄には、これから使われるURLの形をそのまま置く。 acme という語だけを見せて「識別子です」と説明するより、 tasktasktask.work/o/acme の acme を打ってもらうほうが速い。

候補は自動で入れない。 組織名は「株式会社アクメ」のような日本語で入ってくるので、そこから作れる候補が無い。 入れられない欄に、入れられるふりをさせない。
