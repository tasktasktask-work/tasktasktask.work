スレッドを立てる

WEB / WEB-3 の子として
WEB-3 検索の要件をどうするか の子として立てます。親は下の欄で変えられます。

種別はあとから変えられません。議論からその場で課題を作りたくなったら、 課題を別に立てて、この議論を親にしてください。

両方入れるか、両方空けるかのどちらかです。片方だけだと、 ガントに置けるのか置けないのかが決まりません。

タグ
一覧から選ぶ

タグの欄に名前を打つところが無い理由

タグの欄は、畳んだチェックの一覧だけである。 スレッド詳細の属性欄にある「名前を打って足す」は、ここには置いていない。

この画面には保存が一つしかなく、送られるのは常に選んだ全体である。 「一つ足す」という操作がそもそも存在しない。 それでも入力欄を置くと、打った名前がいつ効くのかが読めなくなる。 打った時点なのか、立てたときなのか。

期間の欄が消えるとき

種別を議論か質問に変えると、開始日と終了日の欄ごと消える。 期間を持てるのは課題だけだからである。

灰色にして残すのではなく、消す。 無効な欄が並んでいると、いつ有効になるのかを探すことになる。 種別を変えれば戻ってくる、というのは、消えたほうがかえって伝わる。

親を番号で打ち込む

プロジェクトのスレッドが数百件になると、選択肢の一覧からは選べない。 そこでスレッド番号を打ち込む形にした。 WEB-3 でも 3 でも受ける。

親にしたいスレッドは、たいてい直前に見ている。 そちらの画面から「関連する課題を作成する」で来れば、この欄はもう埋まっている。

存在しない番号を渡されたとき

問い合わせに書かれた番号は、この画面を出す前に一度引く。 引けなければ、上の帯を出さずに空の欄で開く。

そのまま入力欄に入れて開くと、本文を書き終えてから「その番号はありません」と断ることになる。 番号は組織の中で通しなので、他のプロジェクトの番号を打ち込める。そちらも同じ扱いになる。

誰がこの画面を開けるか

そのプロジェクトを閲覧できる人なら誰でも開ける。 組織管理者である必要も、 プロジェクト管理者である必要もない。

アーカイブされたプロジェクトでは、この画面は開かない。 一覧の右上の押しボタンも出ない。
