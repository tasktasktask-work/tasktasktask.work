平らに並べる理由

階層に深さの制限がないため、入れ子で表示すると深いところが読めなくなる。 そして担当者やタグで絞り込むと、階層はかえって邪魔になる。 絞り込みの結果として残った子だけが、親のいない状態でインデントされて並ぶことになる。

代わりに、行ごとに ← 親 WEB-3 と 子 2件 → のリンクを置く。 構造を辿りたいときはここから移動する。

構造そのものを俯瞰したいときはガントを見る。 あちらは入れ子で並ぶ。同じデータを二つの画面で違う形に見せているが、 一方は探すための画面、もう一方は計画を読むための画面である。

絞り込みの既定値

絞り込み既定理由
完了を隠すオン進捗率100のものは、通常の作業では見る必要がない
アーカイブ済みを表示オフ畳んだものを既定で出すと、畳んだ意味がなくなる
種別 / 担当者 / タグすべて最初は全体を見せ、絞るのは利用者に任せる
並び順更新の新しい順動いているものが上に来る

最後の行について

WEB-5 はアーカイブ済みだが、絞り込みがオフでも表示されている。 活動中の子スレッドを持つためである。

親をアーカイブしても子は連鎖しない。 そのままだと、動いている子が親ごと視界から消える。 そこで、活動中の子を持つアーカイブ済みスレッドは読み取り専用として一覧に残す。
