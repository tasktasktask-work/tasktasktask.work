WEB / 設定
スレッド ガント メンバー 設定

キーは変えられません。WEB-128 として書かれた記録が、過去を指せなくなるためです。

公開設定

いまは公開です。組織のメンバー全員が見られます。

アーカイブ

アーカイブすると、中のスレッドがまとめて読み取り専用になります。個々のスレッドの状態は書き換えないので、解除すれば元どおりです。

削除

アーカイブしたプロジェクトだけを削除できます。一覧から一手で消えないようにしてあります。

危ない操作ほど、下に置く

上から、名前と説明、公開設定、アーカイブ、削除。 取り返しのつかなさの順に並んでいる。

削除の押しボタンは、アーカイブするまで押せない。 「先にアーカイブしてください」と後から言うのではなく、 押せない状態と、その理由を先に見せる。

削除だけ、出す相手が違う

プロジェクト管理者がこの画面を開くと、削除の欄には 「削除できるのは組織管理者だけです」とだけ出る。

押せないボタンを見せて断るより、押しボタンごと出さない。 アーカイブの押しボタンを畳む前から見せているのとは、扱いを変えている。 あちらは自分でできることの前提を伝えており、こちらは自分にはできない。

切り替えの確認で、人数を言う

公開から非公開へ切り替えるとき、確認の文には いま登録されている人数が入る。

「非公開になります」だけだと、自分以外に誰が残るのかが分からない。 ゼロ人のまま切り替えたことに気づけるようにしてある。
