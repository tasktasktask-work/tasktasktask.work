メールアドレスを出さない

組織のメンバー一覧では、組織管理者にだけメールアドレスを見せている。 招待が重複していないか、誰を外すのかを確かめるのに要るためである。

この画面では誰にも出さない。 選ぶ相手はすでに組織に居る人で、表示名で足りる。 プロジェクト管理者は組織管理者とは限らない。

組織管理者がこの一覧に並ばない

組織管理者は行を持たなくても全プロジェクトの管理者として扱われる。 そのため、ここに名前が無い人にも中身が見えている。

黙っていると「一覧に居ないのに見えている人が居る」と読めてしまうので、 画面の上で先に断っている。

公開プロジェクトでも開ける

公開のあいだ、この一覧は閲覧の範囲を変えない。 それでも足したり外したりできる。

非公開に切り替えてから人を入れる順にすると、 誰も入っていない非公開プロジェクトができる時間が生まれる。 その時間を作らずに済むよう、先に揃えられるようにしてある。 公開のときは、効いていないことを画面の上で断る。
