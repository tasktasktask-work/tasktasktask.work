招待の重複や、誰を外すのかを確かめるのに要るのは管理する側だけである。 他のメンバーには表示名と役割があれば足りる。

出し分けは SQL の中で行う。 画面で絞る形にすると、その一箇所を忘れたときに漏れる。

失敗は、その行に出す

役割を変える操作は、ひとつだけ失敗しうる。 最後の組織管理者を降ろそうとしたときである。

組織管理者がいなくなります。先に別の人を組織管理者にしてください。

画面の上部にまとめて出すと、誰について起きたのかが分からなくなる。 この知らせは、まさにその一人についてのものである。

外す操作には確認を挟む。 外された人にはその組織の何も見えなくなり、戻す手段は招待し直すことだけである。
