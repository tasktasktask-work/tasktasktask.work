読み取れるようにしていること

  • プロジェクトキーをカードの左上に置く。この文字列が WEB-128 の前半になる
  • 非公開かどうかをキーの隣に添える。公開のものには何も書かない
  • 種別ごとの件数を出す。議論と質問が多いプロジェクトは、まだ形が定まっていないという意味になる
  • アーカイブ済みは薄く表示し、既定で出す。プロジェクトの数は多くないので、隠すより並べたほうが探しやすい
スレッド一覧との違い

スレッド一覧ではアーカイブ済みを既定で隠す。 こちらでは既定で出す。 件数の桁が違うためで、数万件の中に混ぜると読めなくなるが、数個なら並んでいたほうが早い。
