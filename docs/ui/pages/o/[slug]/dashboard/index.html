読み取れるようにしていること

プロジェクトが混在するので、識別子を必ず出す。 WEB-7 と BILL-31 が並んでいれば、どちらの話かがその場でわかる。

期限までの残り日数を出す。 期間は日付だけを持つので、残りも日数で表せる。 3日を切ったものは黄色にする。

期間未設定の課題は、リストの中でも黄色の印を付ける。 ガントで別枠に出すのと同じ理由で、日付を入れるべき課題を見えるようにしておく。

通知を同じ画面に置く理由

「今日、自分は何をやるのか」という問いに対する答えは二つある。 担当している仕事と、自分に向けて誰かが言ったことである。 別の画面に分けると、片方を見落とす。

未読は地を朱に染める。 ウォッチが自動で付かない仕様のため、 ここに出る通知はどれも誰かが意図的に自分へ向けたものになる。
