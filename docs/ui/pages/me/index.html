この設定は、所属しているすべての組織に効きます。 きっかけごとの細かい切り替えは持っていません。 止めているあいだも、通知そのものは組織ごとの一覧に積まれ続けます。 ログイン用のリンクと招待は、この設定に関わらず届きます。

左帯が無い

組織の中の画面には、プロジェクトが並ぶ左帯が付く。 この画面には付かない。組織に属していない人も、ここへ来られる必要があるからである。

招待を受け取る前の人も、最後の組織から抜けた人も、アカウントは持っている。 そのとき左帯に並べるものは一つも無い。

枠は組織の一覧と同じものを使う。 ロゴを押すとそこへ戻る。

なぜ組織の下に置かないか

切り替える値は users にある。 所属しているすべての組織に効く。

URL は、その設定がどこまで効くかを語る

/o/{slug}/settings/me に置くと、その組織だけの設定に見える。 三つの組織に居る人は三箇所を止めて回り、一つ見落として届き続ける。

実際には一箇所で全部止まる。 止めたつもりで届き続けるより、止めるつもりの無かったものまで止まるほうが、まだ気づける。

左帯の「わたし」からもここへ来られる。 ただしリンクの行き先は組織の外へ出る。

スイッチの押し方

チェックと保存に分けていない。押した時点で切り替わる。

分けると、切ったつもりで保存を押していない状態が作れる。 止めたい人は、たいてい通知が届いた直後に苛立って開いている。

ここに増えていくもの

表示名の変更、パスワードの設定、退会。 アカウントの設定に置いてある分は、この画面に足していくことになる。
