ログイン画面へ

期限切れ、取り消し済み、使用済み、そもそも存在しない。 四つの理由で、それぞれ違う文言を出す。 マジックリンクと違って、 受け取った人には自分で送り直す手段がないためである。 何が起きたのかが分からないと、誰に頼めばよいのかも分からない。

開いただけでは、何も起きない

この画面は招待の中身を読むだけで、参加は送信して初めて成立する。 開いた時点で受諾すると、リンクを先読みするメールソフトが勝手に消費してしまう。

参加したあと

その場でログイン状態にし、参加した組織のプロジェクト一覧へ送る。 別のアカウントでログインしていた場合も、招待された側へ切り替わる。 招待リンクを開けたこと自体が、そのアドレスの持ち主である証拠になっているためである。
