未ログインのとき

このURLのままログイン画面を出す。 /login へは送らない。

送らない理由は二つある。 ひとつは、送ると戻り先を持ち回る必要が出ること。 もうひとつは、マジックリンクの着地点がここだからである。 リンクを踏んだ人は必ずこのURLへ来る。 入れていれば組織の一覧、入れていなければログイン画面、と一枚で受けられる。

戻り先は相対で返す

マジックリンクの着地点（/auth/magic）から、この画面へ戻す。 そのときの行き先を、リクエストから組んではいけない。

NextRequest の nextUrl は Host ヘッダを見ず、 サーバが束ねているホスト名を返す。本番は 0.0.0.0 である。 デプロイに、踏んだ内容を書いてある。
