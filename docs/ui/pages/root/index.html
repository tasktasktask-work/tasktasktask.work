招待を受け取ると、そのリンクから参加できます。

アカウントはあるのに、どこにも所属していない状態は起こりうる。 組織から外されたあとがそれである。

この状態の人にも、行き先がひとつある。 見出しの右の組織を作るである。 すでにログインしているので、メールでの確認は挟まない。 組織名と slug を決めれば、その人が組織管理者になる。

ボタンは組織を持っている人の画面にも同じ位置に出る。 プロジェクト一覧の「新しいプロジェクト」と揃えた。 一覧の画面で新しく作るものは、見出しの右にある。

押した先はこの画面の中ではなく、/signup である。 そこは未ログインの人も通る画面で、組織名と slug を訊く欄はそちらに置いてある。 同じ欄を二箇所に持つと、片方だけに予約語の判定が入る日が来る。

未ログインのとき

このURLのままログイン画面を出す。 /login へは送らない。

送らない理由は二つある。 ひとつは、送ると戻り先を持ち回る必要が出ること。 もうひとつは、マジックリンクの着地点がここだからである。 リンクを踏んだ人は必ずこのURLへ来る。 入れていれば組織の一覧、入れていなければログイン画面、と一枚で受けられる。

戻り先は相対で返す

マジックリンクの着地点（/auth/magic）から、この画面へ戻す。 そのときの行き先を、リクエストから組んではいけない。

NextRequest の nextUrl は Host ヘッダを見ず、 サーバが束ねているホスト名を返す。本番は 0.0.0.0 である。 デプロイに、踏んだ内容を書いてある。
