組織を新しく作る

組織を作る入口を、いちばん下に置く

この画面に来る人のほとんどは、すでに組織の中にいる。 組織を新しく作るのは初回の一度きりで、 同じ人がもう一度使うことはめったにない。 だからカードのいちばん下に、罫線を挟んで置く。

この画面はどのURLにも現れるので、 /o/acme/p/WEB/t/128 を開いて足止めされた人の目にもこの入口が入る。 そこで押されても困らない。押した先で作られるのは新しい組織であって、 いま見ようとしている組織には何も起きない。

この配置にした理由

パスワードの下に「パスワードをお忘れですか」というリンクを置かない。 代わりに、マジックリンクのボタンをその役割に充てている。

パスワードを忘れた人はマジックリンクで入り、設定画面から入れ直す。 これによりパスワード再設定の画面とトークンの仕組みが不要になる。 補足の一文で、その使い方を伝えている。

ロックされている状態

パスワードの入力に10回連続で失敗するとロックがかかる。 時間では解除されない。

パスワードでのログインが停止しています

連続して失敗したため、このアカウントのパスワードログインを止めています。 下のボタンからログイン用リンクを受け取ると、その場で解除されます。

ロックの画面ではパスワード欄を消す。 入力しても通らないものを残しておくと、利用者は何度も試すことになる。

解除の方法をその場に書いているのは、 アカウントロックが第三者によって引き起こされうるためである。 身に覚えのない人が、理由も出口もわからないまま止まることを避ける。

招待からの登録

招待リンクを開いた人には、表示名とパスワードを設定する画面を出す。 メールアドレスは招待で確定しているので変更させない。 登録が済んだ時点でログイン状態にし、その組織のプロジェクト一覧へ送る。
