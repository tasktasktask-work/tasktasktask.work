移行を四本当て、アプリを入れ替えた。 そこから四つの不具合が出た。どれも手元では一度も現れなかったものである。 最後に、そのうち二つを捕まえる手段を入れた。

出す前に確かめたこと

未適用の移行が四本あり、うち一本に CREATE INDEX CONCURRENTLY が入っていた。 トランザクションを張らない移行を本物のデータベースへ流すのは初めてだったので、 空のデータベースを作って本番と同じ状態にし、コンテナが打つのと同じコマンドで通した。

そのうえで、わざと落とした。索引の作成だけが失敗するイベントトリガを仕掛けている。

この予行は当たった。本番の反映そのものは、何事もなく通っている。

出したあとに出た四つ

1. マジックリンクの着地が 0.0.0.0 へ飛ぶ

着地点がリクエストから絶対URLを組んでいた。 NextRequest の nextUrl は Host ヘッダを見ず、 サーバーが束ねているホスト名を返す。本番は HOSTNAME=0.0.0.0 である。

プロトコルは X-Forwarded-Proto が効くのに、ホストは効かない。 行き先を相対にして直した。

2. CSS が画面に届いていない

スクリーンショットで気づいた。カードが素のリンクとして縦に並んでいた。

docs/theme.css には資料だけで使う区画がある。 .card と .badge がそこに残ったまま、画面から使われていた。 型検査もビルドもテストも通り、ページモックは正しく描かれる。 崩れるのは本物の画面だけである。

数えたら8種あった。組織の一覧のカードだけでなく、 スレッド一覧の「親からはみ出し」も、担当スレッドの残り日数も、 枠のない素の文字で並んでいた。

規則を @shared ブロックへ移し、 定義の無い class を pnpm check が弾くようにした。

3. コメントを一つも投稿できない

「blob は中身が空です」と出て止まる。

添付を付けなくても、ファイルの欄は送られてくる。 それを「名前が空の File」として届くものと決めつけ、名前の有無で見分けていた。 本番では名前が blob で届いた。 符号化の途中で File が Blob になると名前が失われ、 仕様どおり blob という既定の名前が付く。

「何も選んでいない」と「空のファイルを選んだ」は、届いた時点では見分けられない。 大きさ 0 のものは選ばれなかったものとして落とすことにした。

4. 保存すると入力欄が元の値へ戻る

担当者を変えると、保存はされるのに選択欄が変更前へ戻る。 読み込み直すと新しい値が出る。

ここで一度、直したつもりで直っていなかった。 defaultValue を value に変えただけで済ませた。

react-dom を読んで分かったのは、reset() がフォームの要素に対して呼ばれることだった。 制御しているかどうかに関わらず DOM の値が戻り、 React 側の状態は動かないので描き直しが起きない。

// recursivelyResetForms
5 === fiber.tag && fiber.flags & 1024 && fiber.stateNode.reset();

止め方も同じ場所にあった。送信の既定動作が止まっているとき、 React は処理の中身を null にして呼ぶので、reset を挟まない。

if (nativeEvent.defaultPrevented) {
  startHostTransition(maybeTargetInst, pendingState, null, formData);
}                                                 // ↑ null なら noop

同じ書き方が7箇所にあった。担当者だけでなく、進捗、期間、親、 スレッドの本文、組織名、役割、プロジェクトの名前と説明、権限、タグの名前。 useField と withoutReset にまとめて、すべてに当てた。

「保存しました」を出していなかった欄にも足した。 出すのは、見えている値が保存済みの値と揃っているあいだだけである。

ブラウザで押す手段を入れた

四つのうち二つは、手元でどれだけ確かめても現れなかった。 ファイル欄の符号化も、フォームの reset() も、 リクエストを手で組む試験では通らない層にある。

Playwright を入れた。置いたのは9件だけで、 ブラウザの中でしか起きないものに限ってある。 判定の網は既存の483件が持っている。

四つとも捕まえる

入れたあと、四つの不具合をすべて元のコードに戻して走らせた。 四つとも落ちた。この試験があれば、往復は起きなかった。
