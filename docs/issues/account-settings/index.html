アカウントの設定

概要

いま自分について変えられるものが何もない。 表示名も、パスワードも、メール通知の受け取りも、登録したあとは固定である。

登録の経路によっては、そもそも設定されていないものがある。

入り方パスワード表示名
招待から登録そのとき決めるそのとき決める
pnpm org:create設定されない引数で決まる

下の行で作られた人は、マジックリンクでしか入れない。 入れはするので止まりはしないが、パスワードを持てないままである。

先送りとした理由

マジックリンクがあるので、誰も締め出されない。 パスワードを持たない人も、忘れた人も、 ロックされた人も、同じリンクで入れる。

この機能が無いことで、できなくなる操作が一つもない。 組織とプロジェクトのほうが先に要る。

画面はもうある

2026-09-08 に /me を作った。 通知メールを送るようになり、 止める手段の無いまま送り始めるわけにいかなくなったためである。

いま置いてあるのはメール通知の切り替え一つだけで、 残りはこの画面に足していくことになる。

項目いま要ること
メール通知あるusers.email_notifications_enabled の切り替え
表示名まだ変えるとすべての組織での表示が変わる。それでよい
パスワードまだ現在のパスワードを要求する。持っていない人には要求しない
メールアドレスまだ変更後のアドレスへ確認のリンクを送ってから差し替える

置き場所は /settings ではなく /me にした。 組織の下でない点は変わらない。 ひとりが複数の組織に所属するので、 /o/{slug}/ の下に置くと、どの組織で変えたのかという問いが生まれる。

メールアドレスの変更だけは扱いが重い。 アドレスは招待の宛先であり、ログインの識別子でもある。 確認を挟まずに変えられると、乗っ取りの経路になる。
