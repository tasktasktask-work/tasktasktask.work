用例の無い用語

概要

用語集の49語のうち、19語に用例が付いていない。 用例とは、その語を使った開発者とドメインエキスパートの会話である。

用語集の役目は、語の意味を揃えることではない。 その語をどう使うかを揃えることである。 定義文だけを読むと、書いた人が何を心配してその語を立てたのかが伝わらない。 会話の形になっていれば、どこで誤解が起きるのかまで一緒に運べる。

実際、用例を書く途中で食い違いが見つかったことがある。 進捗率の用例を書こうとして、「親の進捗が30%で子が全部100%」という場面を思い浮かべたときに、 それが矛盾ではないことをどこにも書いていないと気づいた。

先送りとした理由

19語はどれも別々の機能に属している。 ガントの作業の中で通知やマジックリンクの用例を書くと、その語をどう使うかを、 いま手元で確かめられないまま想像で書くことになる。

用例は、その機能を実装しているときに書くのがいちばん正確である。 何に迷ったかを覚えているうちなら、迷いどころがそのまま会話になる。

実際、今回書き足した用例は、ガントの聞き取りで実際に交わした問答から取っている。 「担当者で絞れませんか」も「昨日たたんだ枝がまた開いてます」も、この作業の中で出た形である。

どうするか

次にその機能に手を入れるときに、まとめて書く。 通知の7語は次に通知へ触れるとき、認証の3語は認証へ触れるときである。

まとめて片付ける必要はない。 一度に19本の会話を作ると、どれも同じ調子の作り物になる。

数え方

用例の有無は機械的に数えられる。 glossary.html の <article class="term"> のうち、 class="dialogue" を含まないものを数える。

優先度

中。 使えない状態ではないが、用語集の役目の半分しか果たしていない。 機能に触れるたび、その機能の語から潰していく。
