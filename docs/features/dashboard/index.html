Feature 10

担当スレッド一覧

複数のプロジェクトに関わるのが前提の構造では、 「今日、自分は何をやるのか」をプロジェクトごとに見て回ることになる。 その手間をなくすための画面である。

この画面が必要な理由

ひとりのユーザーは複数の組織に所属でき、 ひとつの組織の中でも複数のプロジェクトに関わる。

一方、ガントチャートもスレッド一覧もプロジェクト単位である。 自分が担当している課題が5つのプロジェクトに散っていれば、5枚の画面を開くことになる。

この画面は、組織の中で自分が担当者になっているスレッドを、プロジェクトをまたいで一箇所に集める。

並べるもの

自分が担当者に設定されているスレッドのうち、次を除いたものを並べる。

  • 進捗率が100のもの（絞り込みで表示に切り替えられる）
  • アーカイブされているもの
  • アーカイブされたプロジェクトに属するもの

並び順は、期間の終了日が近い順とする。 期間を持たない議論と質問、および期間未設定の課題は、日付を持つものの後に置く。

行にはプロジェクトを示すプロジェクトキーを必ず出す。 複数のプロジェクトが混ざるため、どこの話かがわからないと判断できない。

非公開プロジェクトとの関係

自分が担当者になっているスレッドしか出ないため、 非公開プロジェクトのものが混ざっても問題は起きない。 担当者に設定されているということは、そのプロジェクトのメンバーだということである。
