<section title="何をすべきか">

  # 何をすべきか

  セッションでの作業内容を .git/COMMIT_NEXTMSG へ追記してください。
  既に記載されている内容に統合できる場合（記載されている修正内容に不備があり、追加で修正した場合など）は、統合してください。
  .git/COMMIT_NEXTMSGが存在しない場合は新規作成してください。

</section>

<section title="コミットメッセージのフォーマット">

  # コミットメッセージのフォーマット

  ## スキルを使用した場合

  ```text
  /{使用したスキル}
  {修正を加えた内容を５行以内で記述してください}
  ```

  ## スキルを使用していない場合

  ```text
  {修正を加えた内容を５行以内で記述してください}
  ```

</section>
